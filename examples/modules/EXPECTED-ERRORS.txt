Each program in errors/ must stop with the error below, run from the example directory:
    kg errors/NAME.kg
The first line is the error as docs/errors.md prints it; the KIND is what the conformance
cases test. The wording of the message is a proposal; the kind and the position are the contract.
Exit status 1, nothing on standard output (the programs print only when they succeed).
In cycle.kg the files are named by their full paths, shown here as <dir>.
